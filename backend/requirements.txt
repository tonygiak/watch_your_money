# tzdata: Python's `zoneinfo` falls back to the OS IANA db on POSIX systems
# (Linux, macOS) but on Windows there is no system db, so tests against
# `Europe/Athens` (per ADR-0005 §3) raise `ZoneInfoNotFoundError`. The
# `tzdata` package is the official PSF-maintained data-only shim recommended
# by the `zoneinfo` docs. Pinned here so `make check` is green on Windows
# dev machines too. Linux production runtimes ignore it (the system db wins).
# This dep was added as drift in S-004 (BLG-0013) and codified by ADR-0011
# in S-005 (`docs/adr/S-005-ADR-0011-Tzdata-codification.md`): standalone
# ADR, exact pin, PyPI already on the outbound allowlist, refresh on every
# `requirements.txt` audit.
